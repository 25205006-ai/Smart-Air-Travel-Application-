# ✈️ Smart Air Travel Booking System (C++)

A console-based airline reservation system implemented in C++. This project demonstrates Object-Oriented Programming (OOP), file handling, templates, and basic system design principles.

---

## 🚀 Features

### 👤 Passenger
• Register and login
• View all available flights
• Search flights:
  - By destination
  - By budget
• Book/reserve seats
• View booking invoices

### 🛠️ Admin
• Secure login
• Add new flights (Domestic / International)

### ✈️ Flight Management
• Supports:
  - Domestic Flights (with tax)
  - International Flights (passport requirement)
• Dynamic seat updates
• Auto-generation of 50 flights if no data exists

### 💾 Persistence (File Handling)
• Flights stored in `flights.txt`
• Passengers stored in `passengers.txt`
• Bookings stored in `bookings.txt`

### 🧠 Concepts Used
• Inheritance & Polymorphism
• Abstract Classes
• Templates
• Exception Handling
• File I/O
• Friend Functions
• STL (`vector`, `stringstream`)
